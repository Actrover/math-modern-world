Mathematical Language and Symbols

Mathematical language uses symbols, numbers, and special words to communicate ideas clearly and briefly.

+ Addition− Subtraction× Multiplication÷ Division= Equal≠ Not equal> Greater than< Less than
Example: “Five is greater than three” can be written as:

Mathematical Expression

A mathematical expression is a combination of numbers, variables, and mathematical operations. It does not need an equal sign.

Example:
3x + 5

Here, 3 is the coefficient, x is the variable, and 5 is the constant.

{ }

Set

A set is a well-defined collection of objects or elements. Elements are commonly written inside braces { }.

Example: A set of vowels:
A = {a, e, i, o, u}
|

Set-Builder Notation

Set-builder notation describes the elements of a set by stating a condition that they must satisfy.

Example: The set of positive even numbers less than 10:
A = {x | x is even, x < 10}

The symbol | can be read as “such that.”

A Venn diagram uses circles to visually show the relationship between sets. The overlapping part represents elements common to both sets.

Reasoning: Deductive and Inductive

Reasoning is the process of using information and logic to reach a conclusion.

🔷 Deductive Reasoning

Starts with a general rule and applies it to a specific case.

Example: All humans need oxygen. Juanito is a human. Therefore, Juanito needs oxygen.

🔶 Inductive Reasoning

Starts with observations or specific examples and forms a general conclusion.

Example: The sun rose every morning in the observations. Therefore, we expect the sun to rise tomorrow.

Easy way to remember: Deductive = General → Specific   |   Inductive = Specific → General
